# CO2 Emissions Data Mining Project

This repository contains an academic data mining and machine learning project focused on the analysis of global daily CO2 emissions across countries and sectors.

## Project Overview
The project investigates how CO2 emissions vary over time using real-world emissions data. It combines exploratory data analysis, time series analysis, anomaly detection, clustering, and forecasting to identify meaningful patterns and structural changes in global emission behavior.

## Main Topics
- Exploratory Data Analysis (EDA)
- Time series pattern analysis
- Structural change detection
- Country comparison through clustering
- Forecasting with LSTM
